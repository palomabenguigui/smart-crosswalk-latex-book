# data/

CSV transcriptions of **published** data used by the Python figures and the recomputation scripts.

Rules (PRD §9, PLAN §6 INC-000):
- Every value is checked against a **rendered image** of the source page, never against extracted PDF text alone.
- Every file records its source (`.bib` key), table number and page in a header comment, and the date it was checked.
- Data is cited in the book wherever it is shown ("adapted from [n]").
